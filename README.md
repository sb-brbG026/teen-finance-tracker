# TeenFlow (ФинТрек) ⚡ — Трекер финансов для подростков

**TeenFlow** — современное мобильное веб-приложение (PWA) для учета личных финансов, созданное специально для подростков (12–18 лет). Сочетает визуал топовых финтех-сервисов (Revolut <18, Monobank, Cleo), копилки на мечту, умного ИИ-наставника, работу в офлайне и синхронизацию с Google Таблицами.

---

## ✨ Основные возможности

1. **Мобильный PWA-формат**:
   - Устанавливается на экран смартфона как нативное приложение (iOS и Android).
   - Работает быстро и полностью автономно (офлайн) благодаря Service Worker и локальной базе `IndexedDB`.
   - Темная и светлая темы с плавным переключением.

2. **Учет доходов и расходов для подростков**:
   - Предустановленные категории: карманные деньги, подработка, подарки, фастфуд и кафе, игры и подписки (Steam, PSN, Discord), транспорт, одежда и кроссовки, развлечения, книги и учеба.
   - Возможность добавлять свои категории с выбором эмодзи и цвета.
   - Быстрый ввод сумм (+1, +2, +5, +10, +50) в 1 клик.

3. **Синхронизация с Google Таблицами**:
   - Подключение личной Google Таблицы через бесплатный вебхук Google Apps Script.
   - Автоматическая отправка операций при наличии интернета.
   - Резервный экспорт/импорт в CSV (Excel) и JSON.

4. **Интерактивная аналитика**:
   - Круговая диаграмма (Donut Chart) распределения трат по категориям.
   - Столбчатый график динамики расходов по дням недели.
   - Шкалы контроля лимитов бюджета по статьям расходов.

5. **ИИ-Ментор "Фин" 🤖**:
   - Автономный эвристический анализ текущих трат пользователя в реальном времени.
   - Обнаружение «латте-фактора» (избыток трат на фастфуд и снеки), расчет темпа накоплений, похвала за сбережения.
   - Интерактивные ответы на частые вопросы подростков ("Как быстрее накопить?", "Стоит ли брать прямо сейчас?", "Правило 50/30/20").
   - Опциональная поддержка Google Gemini API ключа для развернутого диалога.

6. **"Копилка на мечту" (Цели)**:
   - Визуальные карточки накоплений (наушники, приставка, кроссовки).
   - Быстрое пополнение копилки с расчетом оставшихся дней и процентов.

7. **Школа денег & Финансовый квиз**:
   - Понятные иллюстрированные статьи без нудной терминологии: правило 50/30/20, ловушка микротранзакций в играх, правило 48 часов, безопасность от скамеров и дропперов.
   - Мини-тест с начислением опыта и рангов.

## 🚀 Быстрый запуск

### 1. Локальный просмотр на компьютере или в локальной сети:
Вы можете запустить любой локальный статический сервер, например:
```bash
# С помощью Node.js:
npx serve .
# или
npx http-server -p 8080

# С помощью Python:
python -m http.server 8080
```
И откройте в браузере: `http://localhost:8080`.

### 2. Установка как PWA на смартфон:
- **На Android (Chrome / Яндекс.Браузер)**: В меню браузера нажмите **«Установить приложение»** или воспользуйтесь баннером вверху экрана.
- **На iOS (Safari)**: Нажмите кнопку **«Поделиться»** (иконка со стрелкой вверх) -> выберите **«На экран "Домой"»**.

## 📊 Настройка Google Таблицы за 2 минуты

1. Создайте новую таблицу на [sheets.new](https://sheets.new).
2. В верхнем меню выберите **Расширения (Extensions) -> Apps Script**.
3. Скопируйте код из файла `assets/google_apps_script.js` (или из окна настроек приложения) и вставьте в редактор.
4. Нажмите **Развернуть (Deploy) -> Новое развертывание (New deployment)**.
5. Выберите тип: **Веб-приложение (Web app)**.
6. В поле **«У кого есть доступ» (Who has access)** выберите: **«Все» (Anyone)**.
7. Нажмите **Развернуть**, скопируйте полученный **URL веб-приложения**.
8. В TeenFlow перейдите во вкладку **⚙️ Настройки** -> вставьте URL в поле и нажмите **«Сохранить URL»**.
9. Нажмите **«Проверить связь»** для теста. Готово! Все новые операции будут автоматически добавляться в таблицу.
